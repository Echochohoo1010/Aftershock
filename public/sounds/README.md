# Chain Reaction Sound Effects

This directory contains sound effects for the chain reaction panel. Replace these placeholder files with actual sound files in MP3 format:

- `positive.mp3`: A pleasant, uplifting sound for positive chain reactions
- `negative.mp3`: A lower-pitched sound for negative chain reactions
- `neutral.mp3`: A neutral notification sound for neutral chain reactions
- `alert.mp3`: An attention-grabbing sound for alert chain reactions

Recommended sound characteristics:
- Short duration (0.5-1.5 seconds)
- Clear and distinct for each type
- Not too jarring or distracting
- Appropriate volume levels

You can find royalty-free sound effects on websites like:
- [Freesound](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [Mixkit](https://mixkit.co/free-sound-effects/)
